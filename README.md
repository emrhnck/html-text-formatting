# 📝 HTML Text Formatting Tags

A practice repository dedicated to exploring and testing HTML text formatting and semantic tags.

## 🛠️ Tags Practiced
* `<b>` & `<strong>`: Bold and important text
* `<i>` & `<em>`: Italic and emphasized text
* `<small>` & `<big>`: Font size adjustments
* `<del>` & `<ins>`: Deleted and inserted text
* `<sub>` & `<sup>`: Subscript and superscript
